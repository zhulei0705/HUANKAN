# 寰瞰 AI 本地配置与证据约束

AI 为可选增强。未配置时继续使用分类与研究规则，不生成模型执行记录。

在当前 Windows 用户环境变量中自行配置 `AI_ENABLED=true`、`AI_BASE_URL`、`AI_MODEL`。外部 HTTPS 接口还需 `AI_API_KEY`；本机兼容服务可使用 `http://127.0.0.1:端口/v1`。根地址应包含服务实际的 API 前缀，程序在其后添加 `/chat/completions`。不要将真实密钥写入 Git、报告或新闻文本。配置后使用项目 `scripts/start-services.ps1 -RestartBackend` 重启寰瞰后端。

当前适配器使用兼容 Chat Completions 的 JSON 请求和 `response_format=json_object`。不支持此协议的模型需另行适配，不能只填写一个模型名就视为已接入。[官方请求格式](https://developers.openai.com/api/reference/resources/chat)。

在“全球重要事件”的“查看事件研究”中可以发起一次真实官方事件证据分析。来源必须具备有效存储许可、实际原始字节与一致 SHA-256；无法确定单条消息范围时拒绝分析。不会自动抓取未取得许可的文章全文。

新闻进入用户数据段，固定系统约束与来源数据分开。没有工具、数据库写入或命令执行能力。模型返回的标题、摘要、数字、日期、币种、同比／环比与预测属性进行字段一致性检查；逐字摘录记录 Unicode 字符位置。缺少原文支撑则标记需人工审核。模型分析、影响假设与反证均保留输入证据、模型、提示版本、实际执行时刻与原始输出；完成记录不可修改。

字段一致性通过仍不等于语义事实核实。所有模型产物保持待人工审核，不自动写入已核实企业客户／供应商关系，也不构成行情或投资收益预测。中文翻译只显示在实际模型分析区，未经人工审定不会覆盖官方原标题。

当前配置、执行数量和错误结果以 `/api/ai/status`、数据库 `ai_analysis` 及实际验收报告为准。隔离兼容服务测试不等于真实模型能力测试。
