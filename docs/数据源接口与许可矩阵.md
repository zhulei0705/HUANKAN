# 数据源接口与许可矩阵

下一阶段更新：FED的本地Board RSS元数据用途已根据官方免责声明核验并启用，正式历史事件20条；其他来源保持未接入。详见T03-数据真实性与证据验收.md。下表保留首次基线记录。

检查日期2026-10-09。R08/R09 主责，R16/R24评审。官方文档可读不等于本机连接器成功；访问、存储、展示许可分别记录。默认所有来源 PENDING、关闭。

|来源|官方依据/入口|首期接口|状态和依赖|
|---|---|---|---|
|SEC EDGAR|https://www.sec.gov/search-filings/edgar-application-programming-interfaces|https://data.sec.gov/submissions/CIK##########.json|解析器已实现；真实邮箱 User-Agent、CIK名单、许可核验缺失，未请求|
|美联储|https://www.federalreserve.gov/feeds/feeds.htm|https://www.federalreserve.gov/feeds/press_all.xml|RSS解析器已实现；本机连通测试另见报告；存储展示许可待核验|
|GDELT|https://www.gdeltproject.org/data.html|待按正式增量文件文档实现|仅登记，不冒充L0|
|FRED|https://fred.stlouisfed.org/docs/api/fred/|https://api.stlouisfed.org/fred/series/observations|仅登记，需要真实Key和指标许可|
|中国官方/交易所行情|按机构正式文档核验|不假定隐藏接口存在|未接入，未获授权|

SEC API 文档明确使用10位CIK且无需API Key，同时要求自动访问遵守现行政策。不能因此省略真实 User-Agent。美联储提供 RSS 订阅说明，但不将RSS订阅说明视为所有内容的无限商业再分发授权。

核验流程：记录官方条款链接与具体依据，确认使用场景、存储、展示、有效期，再由管理人员更新 source_license 并开启 source_registry。缺少明确依据不得标记 APPROVED。首版未提供页面许可审批接口，避免一键误授权。
