# 寰瞰 HUANKAN

全球金融智能情报平台，Windows 本地优先。美联储与ECB真实RSS、GDELT增量元数据、证据链、SSE回放及中文工作台已通过本轮可验证范围；完整V4.0未完成，真实新发布事件延迟未测。

先阅读 [统一开发状态报告](docs/统一开发状态报告.md)、[项目审计](docs/T00-项目审计报告.md) 和 [本地部署指南](docs/Windows本地部署指南.md)。

目录：backend 是 Java 21/Spring Boot；frontend 是 Vue 3/TypeScript；compose.yml 是 PostgreSQL 16；docs 保存中文设计与实际测试记录；scripts 提供启动与验证。

FED、ECB、GDELT仅启用已核验的限定本地元数据用途；SEC与FRED保持关闭。AI、行情和未开发模块显示实际配置状态。正式库不预置Fixture，实时数量、测试与剩余事项见docs/统一开发状态报告.md及S01–S07报告。


S08—S14可靠性升级说明：见docs/统一开发状态报告.md。
GDELT只下载官方索引确认且批次UTC时间已经到达的文件；历史发现独立游标、缺口和持久重试队列分离。每批证据、版本、Outbox和完成游标在同一事务提交。
SEC继续要求真实联系方式；FRED继续要求用户Key和明确序列白名单，两者还必须通过数据库许可门禁。未配置时不会请求，不影响其他来源。
备份与独立实例恢复：scripts/backup-restore-drill.ps1 -RestoreDrill。操作前阅读docs/S13-备份恢复操作说明.md。不能用恢复演练覆盖正式业务库。

S15—S22 新增国家统计局两个官方 RSS 栏目、ECB SDMX 参考汇率与政策利率，以及规则筛选、实体候选和证据审核工作台。实际数据、回归结果与未完成范围见 [阶段综合验收](docs/S22-全球金融智能研判阶段综合验收.md)。ECB 观测日期不作为新闻发布时间，政策率仅保存官方实际变更日；当前同步最近 90 天，尚未开启官方全历史版本服务。

本地环境变量通过 scripts/load-local-env.ps1 载入，凭证不写入仓库。scripts/start-services.ps1 仅启动本项目后端，使用 Windows 信任库校验证书；scripts/watch-huankan.ps1 提供有限重试的本项目恢复选项，未注册系统开机任务。备份并发新增时会拒绝清单验收，可在本项目停止写入的窗口重试，保持 PostgreSQL 服务和其他项目运行。

## 当前事故门禁

截至S69-INC02，正式原版恢复、R3正式部署、5173切换和新24小时回归分别均为No-Go。旧启动与观察脚本是历史工具，不构成当前执行授权；操作前以[统一开发状态报告](docs/统一开发状态报告.md)及[INC02恢复准入报告](docs/S69-INC02-原版本恢复准入报告.md)为准。

GitHub版本包含源码、配置模板、工具和报告；运行目录、构建产物、凭证及原始事故证据留在本机，说明见[本地证据目录](docs/evidence/README.md)。首次检出后不要直接运行启动、迁移、采集或浏览器脚本连接既有服务。
